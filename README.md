## Что такое VLESS и Reality — коротко

- **VLESS** — лёгкий протокол из проекта Xray, без лишнего шифрования поверх TLS.
- **Reality** — маскировка: для провайдера подключение выглядит как обычный заход на популярный сайт, без своего «подозрительного» сертификата.
- **Транспорт** — как именно ходят данные: TCP, gRPC, **XHTTP**, WebSocket. Сегодня именно от транспорта зависит, режут вас или нет.

Ключ выглядит так: `vless://uuid@адрес:443?security=reality&sni=…&type=tcp#Название`.

## Почему VLESS Reality перестал работать

ТСПУ больше не ищет «подпись протокола». Он смотрит на **поведение**:
1. **Несовпадение домена и IP.** SNI говорит «я google.com», а IP принадлежит хостеру в Нидерландах. Подозрительно.
2. **Шаблон соединений.** Клиенты открывают много параллельных TLS-соединений к одному IP. Обычный браузер так себя не ведёт.
3. **Объём.** Соединение к зарубежному IP «замораживают» после ~16 КБ («блок 16 КБ»): пинг есть, данные не идут.
4. **IP-репутация.** Целые подсети популярных хостеров (например, Hostkey) режутся у российских провайдеров целиком.

Итог: **«голый» VLESS + Reality по TCP** на мобильном интернете во многих регионах не живёт. На домашнем Wi-Fi ещё работает, но всё реже.

## VLESS не работает: чек-лист

1. **Пинг есть, сайты не грузятся** → «блок 16 КБ». Перейдите на XHTTP или Hysteria2.
2. **Ошибка `handshake` / `timeout`** → IP сервера заблокирован или неверный SNI. Обновите подписку.
3. **Работает на Wi-Fi, не работает на мобильном** → вам нужен XHTTP.
4. **На мобильном не работает вообще ничего, даже Google** → [белые списки](https://github.com/Filizaker2/belye-spiski-obhod).
5. **Telegram и YouTube не работают, остальное работает** → [отдельный разбор](https://github.com/Filizaker2/ne-rabotaet-youtube-telegram).

## Для тех, кто держит свой сервер

Если поднимаете Xray сами (3x-ui, Marzban, Remnawave):
- Добавьте **XHTTP** (`network: xhttp`) рядом с Reality TCP и отдайте оба варианта в подписке.
- Для Reality используйте **selfsteal**: свой домен и сертификат на самом сервере (Caddy на `127.0.0.1`) вместо чужого сайта в `dest`. Так SNI совпадает с IP, и пропадает признак №1 из списка выше.
- Добавьте **Hysteria2 с Salamander** на UDP. Используйте тот же сертификат.
- Держите серверы **минимум у двух хостеров**: целые подсети режут.
- Проверяйте доступность из российских сетей, а не со своего компьютера. Ваш компьютер может сам сидеть в VPN.
